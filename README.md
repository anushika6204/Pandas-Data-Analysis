# Pandas Data Analysis

 practice of data analysis using **Pandas**, **Matplotlib** and **Seaborn**. Each project is in its own folder.

## Projects

| # | Project | Dataset | Topics Covered |
|---|---------|---------|----------------|
| 1 | [Adult Income Analysis](adult-income-analysis/) | [Kaggle](https://www.kaggle.com/datasets/uciml/adult-census-income) | EDA, groupby, apply, replace, astype, boxplot, countplot |
| 2 | [Google Play Store Data Analysis](google-playstore-data-analysis/) | [Kaggle](https://www.kaggle.com/datasets/lava18/google-play-store-apps) | head, tail, shape, info, describe, str.contains, groupby, value_counts, replace, astype, sort_values, iloc |

## Tools Used

- Python 3
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/your-username/pandas-data-analysis.git
   ```
2. Install the libraries:
   ```
   pip install pandas matplotlib seaborn jupyter
   ```
3. Open Jupyter Notebook:
   ```
   jupyter notebook
   ```
4. Open any project folder and run the `.ipynb` file.
